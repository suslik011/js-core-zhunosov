Closures in my code (Замыкания в моем коде)
В данной лабораторной работе замыкания (closures) были применены при реализации функций memoize(fn) и counter(initialValue). Замыкание возникает тогда, когда внутренняя функция сохраняет доступ к переменным из своей внешней (родительской) области видимости даже после того, как внешняя функция завершила свое выполнение.

В функции memoize мы создаем коллекцию cache = new Map(). Возвращаемая анонимная функция «замыкает» в себе эту переменную cache, благодаря чему результаты вычислений сохраняются между повторными вызовами без использования глобальных переменных. В случае counter переменная count находится в приватной области видимости фабричной функции, а методы inc(), dec() и value() образуют замыкание над ней. Это гарантирует инкапсуляцию данных и предотвращает случайное изменение счетчика извне.
